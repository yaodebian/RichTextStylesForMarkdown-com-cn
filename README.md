# RichTextStylesForMarkdown

本项目收录适用于微信公众号等场景的 Markdown 富文本排版主题样式。

适用工具：https://markdown.com.cn/editor/

## 主题列表

### 专业阅读橙

- **文件**: [`geek-reconstruction.css`](./geek-reconstruction.css)
- **简介**: 简洁专业的微信公众号 Markdown 排版样式，以橙红色为强调色。包含标题左侧竖线、圆角引用块、代码块、表格、链接等完整排版支持，并针对小屏设备做了适配。

### 深流 (Deep Flow)

- **文件**: [`shenliu.css`](./shenliu.css)
- **简介**: 面向深度阅读的微信公众号 Markdown 排版样式，以深青蓝绿 (#264653) 为主色调，整体风格沉静专注。包含带标签式标题、圆角引用块、深色代码块、表格等完整排版支持，并针对移动端做了适配。
